# 건의 #235 후속 — 네이버부동산 최저가와 비교 (보류)

## 요청
> 내 최저가랑 네이버부동산에 나온 최저가를 찾아서 알려 줄수 있어?

매물관리에서 같은 단지·같은 전용면적·같은 거래 중 내 최저가 매물(이미 '최저가' 표시 배포됨, 커밋 757bf2d)과
네이버부동산에 올라온 같은 조건 매물의 최저 호가를 함께 보여 달라는 요청.

## 자동 반영하지 않은 이유
- 외부 서비스 연동: 네이버부동산은 공개 API가 없고, 비공식 내부 API/스크래핑은 이용약관·차단(HTTP 403/429) 위험이 있음
  (`app/api/import-listing/route.ts`도 "네이버 부동산은 자동 수집을 막을 수 있으니" 안내 중).
- 서버 API(`app/api/**`) 신규 작성이 필요 → 자동 처리 규칙상 보류 대상.

## 관리자 결정이 필요한 선택지
1. **링크만 제공(안전)**: 매물 카드의 '최저가' 옆에 "네이버에서 보기" 버튼 → 단지명으로 네이버부동산 검색 화면을 새 창으로 엶.
   가격 비교는 사람이 눈으로 확인. 외부 호출 없음.
2. **서버에서 네이버 호가 조회**: `app/api/naver-lowest/route.ts`에서 단지 ID·전용면적·거래종류로 비공식 API 조회 후 최저가 반환.
   약관/차단 리스크, 캐싱 필요, 유지보수 부담.
3. **공식 데이터 대체**: 국토부 실거래가(이미 market-price 화면 사용)와 비교 — 호가가 아니라 실거래가라 요청과는 다름.

추천: 1번을 먼저 반영하고, 2번은 관리자 판단 후 진행.
